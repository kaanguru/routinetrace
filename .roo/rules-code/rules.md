# RoutineTrace Rules

## 1. Purpose
RoutineTrace is a multi-platform routine to-do list Android app tracking daily/weekly/monthly tasks. Focus on:
- Success percentage calculation for recurring tasks
- Integration with ReactNative Expo
- Effective health/happiness tracking

## 2. Database Schema

### 2.1 Tasks Table
- **Mandatory fields**: `id`, `title`, `is_complete`, `user_id`, `created_at`, `updated_at`
- **Optional fields**: `position`, `repeat_on_wk`, `repeat_frequency`, `repeat_period`, `notes`

```sql
CREATE TABLE public.tasks (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  title TEXT NOT NULL,
  notes TEXT,
  created_at TIMESTAMPTZ DEFAULT now() NOT NULL,
  updated_at TIMESTAMPTZ,
  is_complete BOOLEAN DEFAULT false,
  user_id UUID DEFAULT auth.uid() NOT NULL,
  position SMALLINT,
  repeat_on_wk days_of_week[],
  repeat_frequency SMALLINT,
  repeat_period public.repeat_period
);

CREATE INDEX ON public.tasks USING GIN(repeat_on_wk);
```

### 2.2 Checklist Items
- **Required fields**: `content`, `task_id`
- Tracks nested checklist items

```sql
CREATE TABLE checklistitems (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  content TEXT NOT NULL,
  task_id BIGINT REFERENCES tasks(id) ON DELETE CASCADE NOT NULL
);

CREATE INDEX ON checklistitems(task_id);
```

## 3. Tech Stack Requirements
- **Functional programming model**:
  - Only functional components
  - Immutable declarations (`const`)
- **Immutable props**: All props should be treated as readonly
- **State management**:
  - Global: Use AsyncStorage
  - Never mutate `utils/supabase.ts`
- **Type safety**:
  - Maintain immutability using `Readonly`
  - Avoid object/array mutation through assignment

## 4. External Libraries
- **Supabase**:
  - Handle Auth & Database services
  - Immutable implementation: `utils/supabase.ts`
- **Error handling**:
  - Use `neverthrow` Result/ResultAsync pattern
  - Import methods:
    ```typescript
    import { ok, err, okAsync, errAsync } from 'neverthrow';
    ```
- **Data management**:
  - Server state: TanStack Query
  - Local state: `useContext` hooks

## 5. UI Guidelines
- **Components**:
  - Use @rneui/themed library
- **Styling**:
  - Colors:
    ```css
    Primary: #ff006e;
    Info: #1982C4;
    Success: #8AC926;
    ```
  - Fonts:
    - Inter_900Black
    - Ubuntu_400Regular
    - DelaGothicOne_400Regular

## 6. Context7 Integration
- API Usage Boundaries:
  - Output between 2k-10k lines
  - Required Library IDs:
    - /expo/expo
    - /supabase/supabase-js
    - /tanstack/query
    - /react-native-elements/react-native-elements

## 7. Rule Interpretation
- Context: "Global state management" requires AsyncStorage for all cross-screen persistence
- Error Handling:
  - Synchronous: Use `ok/err` pattern
  - Asynchronous: Use `okAsync/errAsync` with `ResultAsync`

## 8. Enumerated Types
- Maintain:
  - days_of_week: [Mon, Tue, Wed, Thu, Fri, Sat, Sun] (for weekly recurrence)
  - repeat_period: [Daily, Weekly, Monthly, Yearly] (for task scheduling)
